# eashaan.runs-on.dev

My personal site — **[eashaan.runs-on.dev](https://eashaan.runs-on.dev)**

A single hand-written HTML file: no framework, no build step, no trackers. Everything interactive runs in your browser:

- **RaftKV** — a live 5-node Raft cluster you can crash and watch re-elect a leader
- **LedgerFlow** — a double-entry ledger that refuses to double-charge, with webhook retries and a dead-letter queue
- **OrderBook** — a price-time priority matching engine you can sweep with market orders
- **A terminal** for my toolkit — try `help`, `grep kafka` or `view ai`
- **Ctrl/⌘ + K** to jump anywhere

Recruiter shortcuts: [SDE view](https://eashaan.runs-on.dev/#swe) · [AI/ML view](https://eashaan.runs-on.dev/#ai)

Hosted on GitHub Pages · domain via [runs-on.dev](https://runs-on.dev)
